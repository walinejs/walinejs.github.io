伺服器環境變數

大約 6 分鐘...

你可以透過下列環境變數對 Waline 伺服器進行設定。

注意

環境變數更新後必須重新部署才能生效。

Vercel 需要在 Settings - Environment Variables 中進行設定。

主要設定

環境變數名稱必填備註
SITE_NAME部落格名稱
SITE_URL部落格位址
LOGIN當設為 LOGIN=force 時會要求登入才能留言
SERVER_URL設定 Waline Server 的位址，適合在自動產生的位址不正確時填寫

顯示

環境變數名稱預設值備註
DISABLE_USERAGENTfalse是否隱藏留言者的 UA，預設為否
DISABLE_REGIONfalse是否隱藏留言者的歸屬地
DISABLE_AUTHOR_NOTIFYfalse是否禁止新留言通知
AVATAR_PROXY''頭像的代理位址，留空則不代理
GRAVATAR_STRhttps://seccdn.libravatar.org/avatar/{{mail|md5}}Gravatar 頭像的位址，基於 nunjucks 語法
LEVELS設定後會根據留言數為每個使用者提供等級標籤

等級標籤

根據設定的等級條件以及使用者的留言數，會為留言者增加等級標籤。該功能預設關閉，可以透過設定環境變數 LEVELS 開啟該功能。設定的形式為一串指定數字的逗號串接，例如 0,10,20,50,100,200 表示的就是：

等級條件預設等級標籤
00 <= count < 10潛水
110 <= count < 20冒泡
220 <= count < 50吐槽
350 <= count < 100活躍
4100 <= count < 200話癆
5200 <= count傳說

除了可以自訂等級判斷規則之外，我們還可以在客戶端自訂等級標籤，詳見 等級標籤。

預設只提供了 6 級文案，但並不表示只能有 6 個等級。具體的等級上限是根據你設定的等級判斷規則而來的。增加新的等級建議自行設定對應的文案，若未提供文案，預設顯示的會是 Level 10 這樣的預設文案。

安全

環境變數名稱預設值備註
IPQPS60基於 IP 的留言發表頻率限制，單位為秒。設為 0 則不限制
SECURE_DOMAINS安全網域設定，支援以逗號分隔設定多個網域
AKISMET_KEY70542d86693eAkismet 反垃圾留言服務 Key（預設開啟，不用請設為 false）
COMMENT_AUDITfalse留言發表審核開關。開啟後留言需經管理員審核後才能顯示，因此建議在留言框預設文字上提供提示
RECAPTCHA_V3_KEYreCAPTCHA V3 key，須與客戶端同時設定
RECAPTCHA_V3_SECRETreCAPTCHA V3 secret，供伺服器使用，不可洩漏
TURNSTILE_KEYTurnstile key，須與客戶端同時設定
TURNSTILE_SECRETTurnstile secret，供伺服器使用，不可洩漏

Recaptcha 和 Turnstile

Turnstile Key 和 Secret 可在 https://www.cloudflare.com/zh-cn/products/turnstile/ 申請。

Recaptcha Key 和 Secret 可在 https://www.google.com/recaptcha 申請。

設定時安全網域需要同時加入網站位址和 Waline 伺服器位址（不包含傳輸協定，即 http:// 或 https://）。

郵件

使用者註冊和留言的郵件通知都會用到郵件服務。設定郵件服務相關變數後，使用者註冊會增加電子郵件驗證碼確認相關的操作，用來防止惡意的註冊。

環境變數名稱備註
SMTP_SERVICESMTP 郵件傳送服務供應商
SMTP_HOSTSMTP 伺服器位址
SMTP_PORTSMTP 伺服器連接埠。
SMTP_USERSMTP 使用者名稱
SMTP_PASSSMTP 密碼
SMTP_SECURE是否使用 SSL 連線 SMTP
SENDER_NAME自訂寄送郵件的寄件者
SENDER_EMAIL自訂寄送郵件的寄件位址
AUTHOR_EMAIL站長電子郵件，接收新留言通知

提示

可以在 這裡 查看支援的服務供應商。SMTP_SERVICE 和（SMTP_HOST、SMTP_PORT）任選其一即可，如果清單中沒有對應的 SMTP_SERVICE，則需要設定 SMTP_HOST 和 SMTP_PORT，它們一般可以在電子郵件的設定中找到。

SMTP 的使用者名稱通常均支援使用者的完整電子郵件，而密碼大多與電子郵件密碼相同。

請特別注意部分電子郵件（如 163、qq 電子郵件）使用獨立的 SMTP 密碼。

以下是選填的環境變數：

環境變數名稱備註
MAIL_SUBJECT自訂留言回覆郵件標題
MAIL_TEMPLATE自訂留言回覆郵件內容
MAIL_SUBJECT_ADMIN自訂新留言通知郵件標題
MAIL_TEMPLATE_ADMIN自訂新留言通知郵件內容
