I18n Support

Moins de 1 minute...

Waline has built-in multi-language support, and you can also customize Waline's locale config.

Client

Set Language

You can set the language used by Waline through the lang option. The supported languages are:

  • zh
  • zh-CN
  • zh-TW
  • en
  • en-US
  • jp
  • jp-JP
  • ko
  • ko-KR
  • pt-BR
  • ru
  • ru-RU
  • fr-FR
  • fr
  • vi
  • vi-vn
  • es
  • es-MX

E.g.:

Waline.init({
  el: '#waline',
  // ...
  lang: 'en',
});

Conseil

If you want to help Waline add more language support, we welcome you to send a PR to client/config/i18n.

Customize

You can customize the language through the locales option, or set some fields to overwrite the existing UI text.

For details, see Cookbook → Customize Locale.

Server

The information returned by the server interface will dynamically switch the language based on the lang parameter input by the client.

Customize

You can customize the content for the corresponding language with the locales option, see Cookbook → Customize Locale for details.
