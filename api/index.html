HTTP API exposed by @waline/vercel.

Most JSON responses use Waline's { errno, errmsg, data } envelope. A bearer token returned by POST /api/token can be used for authenticated and administrator operations.

Comment

Read, publish and manage comments.

Get comments

Returns the comment list by default. The type query parameter selects the comment count, recent comments, or the administrator list instead. The shape of the successful response depends on that parameter.

Authorizations:
bearerAuthNone
query Parameters
lang
string

Response language.

type
string
Enum: "list" "count" "recent"

Response mode. list without a path requires an administrator token.

path
string

Article path. Required when type is omitted.

url
string

Comma-separated article paths used by count mode. An empty value returns the site total.

page
integer >= 1
Default: 1

Page number for list modes.

pageSize
integer [ 1 .. 100 ]
Default: 10

Number of comments per page.

sortBy
string
Default: "insertedAt_desc"
Enum: "insertedAt_desc" "insertedAt_asc" "like_desc"

Sort order for the public comment list.

count
integer [ 1 .. 50 ]
Default: 10

Maximum number of comments returned in recent mode.

Responses

Current Waline server

/api/comment

Response samples

  • 200
  • 401
  • 403
Content type
application/json
Example
{
  • "errno": 0,
  • "errmsg": "",
  • "data": {
    • "page": 1,
    • "totalPages": 0,
    • "pageSize": 10,
    • "count": 0,
    • "data": [ ]
    }
}

Get comments as RSS

Returns recent site comments by default. Use path for comments on one article, or email/user_id for replies to a user.

query Parameters
path
string

Article path.

email
string <email>

Comment author email used to find replies.

user_id
string

Comment author user ID used to find replies.

count
integer [ 1 .. 50 ]
Default: 20

Maximum number of RSS items.

Responses
